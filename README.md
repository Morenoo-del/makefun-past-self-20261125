Two lines to my past self: a warning about one very specific Sunday morning at the kitchen table — don't laugh off Dad selling the old Volvo, buy it — and why that moment mattered, because it turned out to be the last thing he ever gave me, and every drive since has kept him riding shotgun beside me. The entry is a single deterministic program: it writes exactly those two lines to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
